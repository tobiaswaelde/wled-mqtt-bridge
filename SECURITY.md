# Security Policy

## Supported versions

Only the latest commit on the `main` branch is supported with security fixes.

## Reporting a vulnerability

Please report potential vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/tobiaswaelde/wled-mqtt-bridge/security/advisories/new). Do not disclose security-sensitive details in public issues or discussions.

Include the affected version or commit, a clear description of the impact, steps to reproduce, and any proposed mitigation. We will acknowledge the report and coordinate a responsible disclosure with you.
